# Dashboard Pontia World 🎡

Este apartado muestra el análisis de *Pontia World* a través de dashboards interactivos diseñados en **Power BI** y **Tableau**.  
Cada herramienta se utilizó para explorar distintos aspectos del dataset, priorizando la claridad visual, la exploración interactiva y la comunicación de insights clave.
