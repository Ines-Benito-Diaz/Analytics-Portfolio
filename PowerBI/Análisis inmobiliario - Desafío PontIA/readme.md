# Dashboard Análisis inmobiliario (Power BI) 🏡

Este dashboard forma parte de un análisis inmobiliario desarrollado previamente en python. Muestra datos inmobiliarios sobre varias ciudades de España.

En él se pueden visualizar métricas clave como:

- 💰 Precio medio de los inmuebles
- 📏 Superficie m² media de los inmuebles
- 🏠 Cantidad y tipos de inmuebles
- 🏙️ Nivel de servicios
- 🛁 Media de baños y habitaciones
- 📢 Cantidad de anuncios publicados según el tipo de operación (alquiler o venta)
- 🧱 Estado de los inmuebles

Además, el dashboard es totalmente interactivo, con 6 filtros principales: Ciudad, Barrio, Tipo de inmueble, Año de construcción, Precio y Superficie m2.
