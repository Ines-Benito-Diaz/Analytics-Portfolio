# Ejercicio "Cines Jayan" 🎬

- **Cines Jayan** es una compañía que tiene en su base de datos “cines” dos tablas donde
guardan los datos relacionados con cada película que emiten y el rating que le ha dado la
crítica y otro donde almacenan la información que representa en que establecimiento se
emite cada película.
- La tabla **“movies”** contiene un código que identifica de forma unívoca a cada película, el
nombre de la película y su rating.
- La tabla **“theatres”** contiene el identificador de cada establecimiento, el código de la
película que emite y su título.
